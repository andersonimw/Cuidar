ℹ️ Como funciona

1. Você cria o ID da família neste módulo

2. Compartilha o ID com o médico via WhatsApp

3. O médico abre o app Cuidar e digita o ID

4. Ele acessa apenas os dados clínicos do paciente

5. Pode adicionar observações médicas visíveis para a família


⚠️ Quando o app for para o Render, o acesso será em tempo real entre dispositivos diferentes. No momento, funciona no mesmo celular.
